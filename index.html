Click Start or press any key to begin. Repeat the sequence to level up.

How to Play

  1. Press Start. Watch which color blinks.
  2. Tap the same color.
  3. Each level adds one more color at the end.
  4. Repeat the full order to level up.
  5. If you tap the wrong color, the game ends. Try again!

Tip: The sounds match the colors—use them to remember.
